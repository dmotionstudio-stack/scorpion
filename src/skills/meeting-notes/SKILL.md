---
name: meeting-notes
description: "Turn rough notes or a transcript into clean meeting minutes with decisions and action items."
---

1. Get the raw notes: pasted text, a file (read_file / read_document), or a transcript.
2. Write the minutes:
   - **Meeting:** title, date and attendees if known (ask once if missing, otherwise leave blank).
   - **Summary:** three to five sentences.
   - **Decisions:** numbered list.
   - **Action items:** a table with columns Task, Owner, Due. Use "?" where the notes don't say.
   - **Open questions:** anything left unresolved.
3. Keep people's names and numbers exactly as written. Drop small talk and repeats.
4. If the user asks, save as `minutes-YYYY-MM-DD.md` in the workspace.
