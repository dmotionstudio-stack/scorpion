---
name: write-an-email
description: "Write an email, letter or message in the right tone, short and ready to send."
---

1. Know three things before writing: who it is for, what the person should do or know after reading it, and the tone (friendly, formal, firm). Ask one short question only if one of them is missing.
2. Write it in this order: a subject line (for an email), a one-line opening, the point in the first two sentences, the details, then the one thing you ask for and by when.
3. Keep sentences short and concrete. No filler such as "I hope this finds you well" unless the user wants it. Use the user's own facts, names and dates exactly; never invent them.
4. Give one version, then offer a shorter or warmer one in a single line.
5. If the user wants a file, save it with write_file as `<topic>-email.md`. Scorpion cannot send it: tell the user to copy it into their mail program.
