---
name: fix-computer-problem
description: "Find out why the computer is slow or something does not work (sound, network, storage, battery) and fix it step by step."
---

1. Ask what happens and since when, in one short question, unless it is already clear.
2. Look first: system_info for memory, storage, battery and network. On Scorpion OS use diagnose for sound, Wi-Fi, Bluetooth, graphics and storage.
3. Name the likely cause in plain words, with the number that shows it (for example "the disk is 97% full" or "no network connection").
4. Fix the smallest thing first: system_control for volume, mute, brightness or Wi-Fi settings; windows_settings to open the right Settings page; pc_cleaner (PC Cleaner agent) for junk files when storage is the problem.
5. Anything that changes something asks the user first. Restart, shut down and emptying the Recycle Bin always ask.
6. Check again after each fix with system_info. If it is not solved after two tries, say what you found and what the user can try next (a restart, a driver update, a technician).
