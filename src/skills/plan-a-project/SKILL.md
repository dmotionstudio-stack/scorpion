---
name: plan-a-project
description: "Turn a big goal into a clear plan: the outcome, steps in order, what could go wrong and the first action."
---

1. Say the goal in one sentence and what "done" looks like. Ask one short question if that is not clear.
2. Break it into 5 to 10 steps in the order they must happen. Each step starts with a verb and can be finished in one sitting. Put them in the chat with update_plan.
3. For each step, note what it needs (a file, an install, a decision, a person) and how you will know it is done.
4. List the two or three things most likely to go wrong, and what you will do about each.
5. Name the very first action and offer to start it now. If the user wants the plan kept, save it with write_file as `plan.md`.
6. Keep it short: a plan the user will read beats a long one.
