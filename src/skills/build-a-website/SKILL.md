---
name: build-a-website
description: "Build a website or web page from an idea: plan, write the files, check the preview and fix what is wrong."
---

1. Ask one short question only if the goal is unclear (what is it for, what should it say). Otherwise start.
2. update_plan with 3 to 5 short steps. Keep it small: one `index.html` with its CSS and JavaScript inside is the fastest, and enough for most pages.
3. Write complete files in the workspace. Semantic HTML, responsive (works at phone width), no external files unless the user asked. Real text, not "lorem ipsum". Write each file once, completely.
4. When you write or edit an .html file, Scorpion opens it in the preview by itself and puts what the page shows and its console errors in the result. Do not start a server for a plain page.
5. If the result lists errors, fix them with edit_file (small edits, not a rewrite). Stop when there are no errors and the page shows what was asked: one or two rounds is enough.
6. Finish with a short summary: the files, how to open the site, and what you would improve next.
