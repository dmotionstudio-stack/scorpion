---
name: summarize-document
description: "Summarize a PDF, Word or text file: the point in two sentences, key facts, decisions and to-dos."
---

1. Read the file with read_document (PDF, Word) or read_file (text). For a long file, read it in parts and keep notes as you go.
2. Write the summary in this shape:
   - **In short:** two sentences a busy person could read alone.
   - **Key points:** 3 to 7 bullets, each one fact, number or argument from the text.
   - **Decisions:** what was decided, by whom if named. Leave the section out if there are none.
   - **To do:** actions with owner and date if the text gives them. Leave out if none.
3. Quote numbers, names and dates exactly as written. Never add facts that are not in the document; if something is unclear, say so.
4. If the user wants it saved, write it next to the original as `<name>-summary.md`.
