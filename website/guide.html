Install Scorpion in two minutes

Pick your computer below. After installing, Scorpion needs one model file, then it works fully offline. Scorpion OS comes with a model built in.

  1. Double-click Scorpion Setup 0.1.8.exe from your downloads.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. This appears because the installer isn't signed with a paid certificate.
  3. Choose where to install. The next page asks how Scorpion keeps its data: Installed (in your Windows profile) or Portable (in a folder next to Scorpion, so it can run from a USB stick). Then click Install.
  4. Open Scorpion from the Start menu or the desktop shortcut. It talks you through setup the first time.

Want Scorpion as your whole desktop? Settings, General, Windows desktop. The switch only changes your own account, and the Windows desktop comes back if anything goes wrong.

To uninstall: Settings, Apps, Installed apps, Scorpion, Uninstall. Your chats, memories and models stay in %APPDATA%\Scorpion until you delete that folder.

  1. Double-click the .dmg for your Mac: Scorpion-0.1.8-arm64.dmg for Apple Silicon, Scorpion-0.1.8.dmg for Intel. (Apple menu, About This Mac: Chip means Apple Silicon, Processor means Intel.)
  2. Drag Scorpion onto the Applications folder.
  3. Open Scorpion from Applications. The first time, macOS says it could not verify Scorpion. Click Done, not Move to Trash.
  4. Open System Settings, Privacy & Security, scroll to Security, click Open Anyway next to "Scorpion" was blocked, and enter your Mac password.
  5. Open Scorpion again and click Open Anyway. From now on it opens normally.

On macOS 14 or older it's simpler: right-click Scorpion in Applications, choose Open, then Open. If macOS says the app "is damaged", run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/Scorpion.app

  1. Ubuntu, Debian and similar: install the .deb with sudo apt install ./scorpion_0.1.8_amd64.deb
  2. Any other distribution: make the AppImage executable and run it: chmod +x Scorpion-0.1.8.AppImage, then ./Scorpion-0.1.8.AppImage
  3. Open Scorpion from your app menu.

Chat, agents, voice, faces, hand gestures and the models work on any distribution. Running the computer for you (apps, windows, volume, Wi-Fi, power) works best on Wayland desktops such as labwc and Sway. Your data is kept in ~/.config/Scorpion.

  1. Write scorpion-os-0.1-amd64.iso to a USB stick of 8 GB or more with Rufus (keep GPT, choose ISO image mode) or balenaEtcher. Everything on the stick is erased.
  2. Plug the stick in and restart. Open the boot menu, usually F12, F9, F11 or Esc at power-on. From Windows: Settings, System, Recovery, Advanced startup, Use a device.
  3. Pick the USB stick, then Try or install Scorpion OS. Scorpion opens as the desktop and nothing on the computer changes.
  4. To keep your chats, models and settings on the stick, choose Scorpion OS, keeping my changes on this USB stick instead (16 GB or more is comfortable).
  5. To install it, click Install on the rail (or say "Install Scorpion OS"). It installs alone or alongside Windows, with a menu to choose at start.

Secure Boot can stay on. If a computer shows a black screen, pick Safe graphics in the boot menu. New versions arrive through updates in Settings, and any system change can be undone.

  1. Plug the stick in and open it.
  2. Any PC, as a whole system: restart and boot from the stick to start Scorpion OS (see the Scorpion OS tab).
  3. Windows, as an app: open the Windows folder and run Scorpion.exe. If Windows warns you, click More info, then Run anyway. Nothing is written to the PC.
  4. Mac: open the Mac folder, double-click the .dmg for your Mac, then double-click Scorpion in the window that opens. Don't drag it to Applications: it runs from the stick.

Scorpion opens with the model on the stick already selected, and everything you do is saved in the scorpion-data folder on the stick.

First start: get a model

Scorpion talks you through setup the first time. It needs one model file: you need internet once for this, or none at all with Scorpion OS, the Complete edition's model pack, or a USB stick.

  • Download: open Settings, Models and click Download next to Qwen3 4B (2.5 GB, recommended).
  • Model pack: unzip it and use Settings, Models, Import .gguf file.
  • Your own: import any .gguf file, or connect Ollama, LM Studio or another server in Settings, Connections.

Then press Ctrl+K to see everything Scorpion can do, or just ask: "List the files in my workspace and summarize the project."

FAQ

Common questions

Does Scorpion send my data anywhere?

No. The model runs on your computer, and your chats, memories, documents, voice and camera are processed there. Online mode is off by default; when you turn it on, the agent can search the web and names its sources.

Can the agent change my files or my computer without asking?

No. It works inside the workspace folder you choose and asks before touching any other folder. Changes and commands wait for your approval unless you turn on Auto-approve, system folders always stay read-only, and restarting or shutting down always asks and waits 30 seconds so you can cancel.

What is Scorpion OS?

A complete operating system with Scorpion as the desktop, built on Ubuntu 24.04 LTS. Boot it from a USB stick to try it with nothing installed, keep your changes on the stick, or install it alone or alongside Windows. It comes with a model and the voice built in.

Can I go back to the normal Windows desktop?

Yes, any time. Scorpion as the desktop is a switch in Settings that only changes your own account. If Scorpion fails to start three times in a row, the Windows desktop starts instead.

Which languages does it speak?

English, French, Haitian Creole, Spanish, Portuguese, German, Russian, Arabic, Hindi, Vietnamese, Korean, Romanian and Yoruba have their own voice. Italian, Chinese, Japanese, Dutch, Polish, Turkish, Ukrainian, Indonesian and Swahili use your computer's voice.

Is it accessible?

Yes. Right after hello, the first start offers bigger text, a screen reader (Narrator on Windows, Orca on Scorpion OS) and an on-screen keyboard. They're in Settings, General too, and the constellation launcher has a plain list view for keyboards and screen readers.

Do I need a graphics card?

No. A graphics card makes answers faster, but Scorpion has a CPU mode too. The Models page tags each model as Fast here, Slower here or Too big for your computer.

How do updates work?

Standard and Complete keep the version you bought, forever. Lifetime gets every new version through the same download link. Scorpion OS gets signed updates through Settings. See what's new on the Updates page.
