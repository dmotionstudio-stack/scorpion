# Scorpion website

The static pages of the Scorpion website, published with GitHub Pages.

The `site/` folder is a copy of the `website` folder in
[dmotionstudio-stack/scorpion](https://github.com/dmotionstudio-stack/scorpion),
without its server code, so checkout and downloads don't run here. Don't edit
`site/` by hand: it's overwritten each time the site is published.
