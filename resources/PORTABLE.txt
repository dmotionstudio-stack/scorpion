Scorpion portable
=================

No installation needed. Unzip this folder anywhere, even a USB stick, and run
Scorpion.exe.

Everything Scorpion saves (chats, settings, memories, documents and downloaded
models) goes in the "scorpion-data" folder next to Scorpion.exe. Nothing is written
to the computer, so you can carry your whole AI around.

Fully offline from the start:
  Copy a .gguf model file into scorpion-data\models before you run Scorpion.
  Scorpion picks it automatically. If Ollama is installed on the computer, Scorpion
  also lists its models (it uses them in place).

Otherwise, open Models in Scorpion and download one (a one-time download).

Windows may show "Windows protected your PC" the first time, because this
build isn't code-signed. Click More info, then Run anyway.

To start fresh, delete the scorpion-data folder (keep an empty one to stay
portable). If you delete the folder completely, Scorpion stores its data in
AppData like the installed version.
