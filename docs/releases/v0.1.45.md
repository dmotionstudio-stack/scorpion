Scorpion 0.1.45 for Windows and macOS: building a web page is much faster. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.44

- **Pages build faster.** When Scorpion writes or edits an `.html` file in Build, it opens the page in the Preview by itself and gives the model what the page shows and what its console says, so the model no longer spends several slow steps starting a server, finding its address and looking at it. A simple page took about 60 seconds with the Qwen3.5 4B, against about 150 to 170 before. Electron's own security warning is left out of that report.
- **No more runaway builds.** A task that keeps trying is told to wrap up after 40 steps and stopped at 60; it says what is done and what is left, and "continue" gives it a fresh budget.
- **Files go where the project is.** With full file access, models sometimes invented folders such as `/home`. The instructions now say a project's files go at relative paths inside the workspace.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
