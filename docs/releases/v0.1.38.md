Scorpion 0.1.38 for Windows and macOS: the internet when you allow it, package installs, and Scorpion changing itself. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.38.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.38-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.38.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.37

- **The internet, when you allow it.** Scorpion no longer tells you it is "fully offline". With Online off, it can ask to search the web or read a page; you get a question each time a task starts, and a yes covers the rest of that task. Turn Online on to skip the question.
- **Installing packages.** In Build, Scorpion installs what a program needs (npm, pip, winget, brew or apt) with its own tool, for up to ten minutes, and asks you first.
- **Changing itself.** In Build, Scorpion can find its own source folder, edit it, run its tests and restart to load the change (always asks before the restart). An installed copy can't be edited; point Scorpion at a source folder instead.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
