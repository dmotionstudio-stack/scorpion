Scorpion 0.1.68 for Windows and Mac: you choose how often Scorpion looks for updates, and it tells you when one is ready. Everything still runs on your computer.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.68.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.68-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.68.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). Macs on 0.1.65 or newer update themselves the same way. If your Mac has an older version, install this one by hand once (open the disk image and drag Scorpion into Applications): it is signed and notarized by Apple, and updates are automatic from then on. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The Windows installer isn't signed with a paid certificate: click **More info → Run anyway** if SmartScreen stops it.

## What's new since 0.1.67

- **Choose how often it looks for updates.** In Settings → General → Updates, "every few hours" is now **every N days, weeks or months**, as you like (a day by default). Scorpion remembers when it last looked, so restarting it does not start the wait again, and Check now still works any time.
- **A notification when an update is available, and when it needs a restart.** A new version is announced when it is found, and again when it has downloaded and Scorpion needs a restart to finish (click it to restart now). There is a switch for these notifications in the same place.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
