Scorpion 0.1.12 for Windows and macOS: Scorpion now updates itself, you arrange the orb's bubbles, and the summon wheel, taskbars and desktop are yours to customize. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.12.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.12-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.12.dmg` |

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**). The README's Install section has the details.

Installing over 0.1.11 keeps your settings, chats and models. This is the last version you need to install by hand.

## What's new since 0.1.11

**Updates from GitHub**
- Scorpion looks for new versions a couple of minutes after it starts and every six hours. **Settings → General → Updates** has **Check now** and a switch to stop it looking by itself. The check only asks GitHub for the newest version number.
- On Windows, a new version downloads in the background and installs when Scorpion restarts, or right away with **Restart and update**.
- On a Mac, and for a portable Windows copy, Scorpion says a new version is out, and **Download** opens it.

**The orb's bubbles**
- **Settings → General → The orb's bubbles**: turn Scorpion's places on or off and put them in your order, add bubbles of your own (an app, a folder, a website or one of Scorpion's actions, each with a name and a colour if you like), choose whether open windows ride the outer ring and how many, and set the bubbles' size and how fast the rings turn.
- Point and pinch, click, or say a bubble's name to open it.

**Taskbars, summon and the desktop**
- The stones taskbar is gone; the edge rail is the default again. Every taskbar starts with Summon, takes the classic bar's choices, follows the theme's colours, and can be resized by dragging its edge.
- The summon dot reaches the screen's real corners, and the summon wheel can be customized: its size, the button's size, recent windows, frosted glass.
- Desktop backgrounds: add your own pictures and switch between them when every app is minimized, and choose full mode's background.
- Windows and taskbars can be resized by dragging, down to a smaller size than before.

**Under the hood**
- Hand gestures follow the hand more closely, with less jitter.
- The model engine runs in a process of its own on Windows and macOS, so a model that crashes no longer takes Scorpion with it.
- A small native helper on Windows makes window listing, focusing and the floating rail faster.
- Settings carry a version and are brought up to date once, when an older Scorpion's settings are read.
- Each release is started and checked as people get it before it's published.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
