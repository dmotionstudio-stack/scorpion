Scorpion 0.1.31 for Windows and macOS: a faster orb that no longer sees your chats. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.31.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.31-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.31.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.30

- **A faster orb.** The orb thinks first only if you ask (**Settings → General → Orb → Thinking**: Off, Quick or Normal; Off is the default), carries a short prompt and only the computer tools (apps, windows, settings, system controls, calculator, the web when Online is on). In a test, the first words came in about half the time with thinking off. The same tab shows where the time went after each answer.
- **The orb never sees your chats.** It no longer gets snippets of other chats or searches them, and what is said to the orb stays out of what chats recall.
- On a Mac, Scorpion now knows in its instructions that it can run the Mac.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
