Scorpion 0.1.48 for Windows and macOS: a clock fix for Scorpion OS updates. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.48.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.48-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.48.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.47

- **Scorpion OS: a wrong clock no longer blocks updates.** If a computer that also has Windows showed updates failing with "release file is not valid yet" (the clock was hours behind, because Windows and Linux read the hardware clock differently), the update check now sets the clock from the internet and tries again, and says clearly what is wrong if it still cannot. New installs beside Windows keep the hardware clock in local time and turn on internet time from the first start. This reaches Scorpion OS through a new ISO; on an installed system now, run `sudo timedatectl set-ntp true` and `sudo timedatectl set-local-rtc 1` once.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
