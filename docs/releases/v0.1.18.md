Scorpion 0.1.18 for Windows and macOS: Build can now run what it builds (a trusted folder, a local server, a preview and a terminal beside the chat), and Unrestricted mode lets Scorpion download and run things without asking, only when you say so. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.18.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.18-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.18.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.17

**Build runs what it builds**
- **Trust folder** (top of a Build chat): in a folder you trust, Scorpion creates and changes files and runs commands (installs, servers, tests) without asking. System folders stay protected, and restarts, shutdowns and the like still ask.
- **Preview and Terminal** beside the chat. Scorpion starts a server for what it made (`start_server`), reads its output and the address it prints, opens the page in the Preview (this computer only), and looks at the page and its console errors (`check_preview`) so it can fix what is broken. The Terminal shows what is running, with Stop and a line to type your own commands. Servers started from Scorpion stop when Scorpion closes.

**Unrestricted mode, only when you choose it**
- Any approval now also offers **Allow for this chat** and **Always (Unrestricted mode)**. Unrestricted mode (also **Settings → General → Privacy**) turns the internet on and lets Scorpion download models (`download_model`), agents (`add_agent`) and files or installers (`download_file`) and run commands without asking. A red strip shows while it is on, every action is written to an activity log (**Show the activity log**), and it only applies to chats you start yourself, never to scheduled runs.
- It is risky: a web page Scorpion reads could try to make it run something harmful. Leave it off unless you want it, and turn it off in Settings or by clicking the strip.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
