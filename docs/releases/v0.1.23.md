Scorpion 0.1.23 for Windows and macOS: a tidier welcome and a clear warning for Light mode. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.23.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.23-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.23.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.22

- **A new welcome.** The hand-gesture and face-recognition steps are gone. The welcome now covers accessibility, the internet (on Scorpion OS), your model, whether Scorpion talks back, and calling it by name. See it again any time in **Settings → General → System → Show the welcome again**.
- **Light mode warns first.** Turning on Light, or **Light while running on battery**, now asks before it takes effect: Light runs Scorpion on the smaller, faster model and won't load other models while it is on, even one you chose. When it swaps, a notice says which model is used instead of yours. Full or Balanced brings your chosen model back. (This restores the behavior 0.1.22 had removed, now with the warning.)

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
