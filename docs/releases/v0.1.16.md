Scorpion 0.1.16 for Windows and macOS: models that used to fail to load now load, and when one can't, Scorpion says why. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

Already on 0.1.15 for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.15

**Bigger models on a small graphics card**
- A model could load and still fail with **"Failed to create context"**: the model fit on the graphics card, but the memory it needs to run didn't, and Scorpion gave up. It now tries fewer layers on the card (then the CPU alone) before failing, and keeps your context size where it can. If nothing fits, the message says the model loads but there isn't enough memory left for its working space, and to lower the context size or pick a smaller model.

**Models that can't load say why, and are checked when you add them**
- Importing a model file the engine can't read (for example a "vision" GGUF made for a different engine version) used to copy it in, make it your chat model, and then fail every chat with a wrong "the file looks damaged, download it again". Now a file is checked when you add it (**Import .gguf file…**, **Use here**, **Copy in**): it takes a second or two, and a file that can't be used is refused before anything is copied, with the reason in plain words.
- A load failure explains itself: made for a different engine version, a kind of model the engine doesn't know yet, not enough memory, extra parts built into the file. Only a really cut-off or damaged file is called damaged.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
