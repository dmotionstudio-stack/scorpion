Scorpion 0.1.19 for Windows and macOS: a small update with an Unrestricted switch in the sidebar and a tidier sidebar. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.19.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.19-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.19.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.18

- **Unrestricted switch in the sidebar**, right under the web search line: **Unrestricted: off / on**. Turning it on asks first. In chats you start, Scorpion then uses the internet freely, downloads models, agents and files, and runs commands without asking, with every action in an activity log (**Settings → General → Privacy**). It is risky, so it stays off until you turn it on; any approval can also offer **Allow for this chat** instead, which covers only that chat.
- **The Library (gallery) button is gone from the sidebar.** Your photos, videos and music are still there: open them from the Library tile on Home.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
