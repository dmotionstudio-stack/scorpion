Scorpion 0.1.71 for Windows and Mac: a desktop menu when you right-click the orb desktop, and fixes for Scorpion OS: Windows programs run on it, and its updates are published. Everything still runs on your computer.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.71.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.71-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.71.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). Macs on 0.1.65 or newer update themselves the same way. If your Mac has an older version, install this one by hand once (open the disk image and drag Scorpion into Applications): it is signed and notarized by Apple, and updates are automatic from then on. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The Windows installer isn't signed with a paid certificate: click **More info → Run anyway** if SmartScreen stops it.

## What's new since 0.1.70

- **Right-click the orb desktop.** When the orb is your desktop (Scorpion OS, or Scorpion as the Windows desktop), right-clicking its empty screen opens the desktop menu: New folder or document, the Desktop folder, and Desktop background. On Scorpion OS right-clicking the empty desktop did nothing before.
- **Scorpion OS runs Windows programs.** Double-click an .exe or .msi (or ask Scorpion to install a Windows program) and it runs through Wine, 64-bit and 32-bit, with winetricks for the extra components some programs need. Wine runs most everyday programs and many games, not all. This is in the next Scorpion OS image.
- **Scorpion OS updates.** Every release now publishes Scorpion's update repository, so Scorpion OS computers see the new version in Software Updater without a new image. (Until now only a full OS build did, and its publishing step was being refused by GitHub's settings.)

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
