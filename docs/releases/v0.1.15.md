Scorpion 0.1.15 for Windows and macOS: a PC Cleaner agent, agents you start with a slash, Settings in tabs that save themselves, and a scan that finds the models already on your computer. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

Already on 0.1.13 for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.13

**Models already on your computer**
- **Settings → Models → Scan this computer for models…** looks in the usual places (Downloads, Documents, Desktop, LM Studio, GPT4All, Jan, the Hugging Face cache, a `Models` folder on any drive, and Ollama), or across the whole computer, and lists the model files it finds. A file counts only if it really is a model.
- **Use here** adds a find where it is, so nothing is copied. **Copy in** puts a copy in Scorpion's folder. **Remove from list** stops using one and never deletes the file. The scan only reads folder listings, and you can stop it.
- Gemma 3 and Llama 3.2 are no longer in the download list (Qwen3 4B, Qwen3.5 4B and gpt-oss 20B are). Models you already downloaded keep working.

**PC Cleaner (Windows)**
- A new agent that finds junk in a fixed list of safe places (your temp folder, crash dumps, npm/pip/uv caches, Edge and Chrome caches, thumbnail caches, and with administrator rights Windows' own temp and log folders), shows what each takes, and deletes only what you pick, after you confirm.
- It never touches Claude or Scorpion session folders, skips files in use, writes a log, and only reports the Recycle Bin and old installers: you empty and delete those yourself.

**Agents with a slash, Settings in tabs**
- The agent dropdown in chat is gone. Type **/** to list the agents: `/coder fix this` makes Coder answer that message and the rest of the chat, `/coder` alone switches, `/scorpion` goes back. Your own agents run by name.
- Settings has four tabs: **General, Models, Agents, Knowledge**, with a second row for a tab's pages. General has tabs of its own: **Look, Desktop, Privacy, Chat, Voice and hands, System**, and reopens on the last one you used.
- Settings keep themselves: a change is saved the moment you make it, with a "✓ Saved" note. Custom instructions save as you type, and the summon shortcut applies when you press Enter or click away.

**Files and folders**
- Full file access is now the default on Windows and macOS: the agent can work anywhere on the computer, and changes and commands still ask first. System folders stay read-only. If you already chose a setting, it stays; choose *Ask before using folders outside the workspace* in Settings → General → Privacy to limit it.
- The Files screen shows your folders and every drive. On a Mac that is the startup disk and what is mounted under /Volumes (it used to list Windows drive letters only), and opening a file and moving it to the Trash now work on macOS. Settings has a button that opens Full Disk Access, where macOS lets an app reach everything. (The Mac parts were tested with stand-in folders, not on a Mac.)

**Smaller**
- Stage slides in only when the pointer touches the edge level with where its cards are, not along the whole edge, and its window covers just that band.
- The Exit full screen button is gone. Ctrl+Esc, or pressing Esc twice, still leaves full screen, and F11 brings it back.
- The Orb look choice in Settings is now saved (it wasn't).
- Listing a model server's models says plainly when the API key is missing or wrong.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
