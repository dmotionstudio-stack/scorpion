Scorpion 0.1.64 for Windows and Mac: the Mac app is now signed and notarized by Apple, so it updates itself like the Windows one. Everything still runs on your computer.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.64.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.64-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.64.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, this is the first version signed with an Apple Developer ID: install it once by hand (open the disk image and drag Scorpion into Applications), and every later version installs itself the same way as on Windows. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The Windows installer isn't signed with a paid certificate: click **More info → Run anyway** if SmartScreen stops it.

## What's new since 0.1.63

- **The Mac app updates itself.** Scorpion for Mac is now signed with an Apple Developer ID and notarized by Apple. macOS opens it without the "unidentified developer" warning, and new versions download in the background and install when Scorpion restarts (or with **Restart and update**), like on Windows. Copies from before this version can't switch over by themselves: install this one by hand once.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
