Scorpion 0.1.43 for Windows and macOS: several chats answered at once, and a chat no longer comes back empty when you leave it while it is answering. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.42

- **Several chats at once.** The model can answer more than one chat at the same time (two by default). Each chat answering has its own working memory; when every one is busy, a new chat waits and says "Waiting for another chat to finish". **Settings → System → Chats answered at once** sets it (1 to 4), and shows how many this computer really allows. Changing it reloads the model.
- **A chat no longer disappears when you leave it.** Going to Home or another chat while Scorpion was loading the model or answering could bring the chat back empty or cut short. Your message is now saved the moment you send it, and the answer so far is kept as it grows.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
