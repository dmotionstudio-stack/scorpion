Scorpion 0.1.41 for Windows and macOS: a Customize panel for the orb's taskbar, and five new agents that build, install and research. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.41.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.41-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.41.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.40

- **Customize the orb's taskbar.** A pencil button on the bar opens a panel: tick or untick any icon (Scorpion, Apps, Files, Power, Network, Battery, Volume, Clock, Notifications, Mail, Chat, USB drives, Orb settings), move or remove the apps, folders and files kept on the bar, and add apps, folders and files. Right-click an empty part of the bar still gives its position, size and look.
- **Five new agents.** **App Builder** (plans, writes, installs, runs and fixes a whole app), **Website Builder** (builds a site and checks it in the preview), **Installer** (installs programs and libraries, then proves they work), **Web Researcher** (looks things up and gives links) and **Scorpion Developer** (changes Scorpion's own code, runs its tests and restarts it). Type `/` in the chat to pick one.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
