Scorpion 0.1.42 for Windows and macOS: 16 new skills and one-click Build buttons. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.42.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.42-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.42.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.41

- **Build a webpage, Build an app.** An empty chat has two buttons: one click switches to Build and starts the request in the message box for you to finish.
- **16 new skills** (20 in all) that Scorpion follows when a job matches: build-a-website, build-an-app, install-software, research-the-web, fix-a-bug, change-scorpion, find-my-files, analyze-spreadsheet, write-an-email, review-code, write-documentation, start-a-project, back-up-folder, fix-computer-problem, clean-up-my-pc and plan-a-project. See them in the Skills page; turn off any you don't want.
- The empty chat no longer says "No internet": the internet is used only when you allow it.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
