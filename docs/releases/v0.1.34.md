Scorpion 0.1.34 for Windows and macOS: Scorpion's own browser, live thinking in the chat, and file access in Chat and the orb. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.33

- **Scorpion's own browser.** The Preview panel beside the chat is now a browser: type a web address or a search in its address bar (back, forward, reload, Inspect; **Open outside** sends the page to your own browser). Every web link you click in Scorpion (in a chat, on the orb, on the taskbar) opens there. A page's own pop-ups and links stay in it; mail links go to your mail program; local files are never opened by address. What the agent opens by itself stays on localhost.
- **You can see it thinking.** While an answer is written, the chat shows the model's reasoning open and growing with a blinking bar and a running time ("Thinking… 12 s"), and under it a moving bar with what it is doing (Starting, Thinking, Working: a tool, Writing) and for how long. Afterwards the reasoning folds to "Thought for 46 s".
- **Scorpion can look through your files, in Chat and in the orb**, with Full file access on: find files by name anywhere ("find my tax return", "*.pdf"), list folders, search inside files and read them (PDF, Word, spreadsheets, text), and open any file or folder, without switching to Build. Changing files and running commands still need Build. Scorpion knows where your Downloads, Pictures, Documents, Desktop, Music and Videos or Movies really are, so "my downloads" just works; a picture, song or video is described and can be opened.
- **On a Mac,** macOS asks the first time for Downloads, Documents and other disks, and when it refuses, Scorpion says exactly what to switch on (Privacy & Security → Files and Folders or Full Disk Access).

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
