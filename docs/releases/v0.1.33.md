Scorpion 0.1.33 for Windows and macOS: a new model, and Nemotron is gone. Everything still runs on your computer: the models, voice, faces and hand gestures never leave it.

## Download

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Scorpion-Setup-0.1.33.exe` |
| Mac with Apple Silicon (M1 to M4) | `Scorpion-0.1.33-arm64.dmg` |
| Mac with an Intel processor | `Scorpion-0.1.33.dmg` |

Already on 0.1.12 or newer for Windows? Scorpion downloads this version by itself and installs it when it restarts (**Settings → General → System → Updates → Check now** to look right away). On a Mac, Scorpion tells you it's out and **Download** opens it. Older versions (0.1.8 to 0.1.11) can't update themselves: install this one over them once, and your chats, models and settings stay.

The installers aren't signed with paid certificates. On Windows, click **More info → Run anyway** if SmartScreen stops it. On a Mac, open Scorpion once, then **System Settings → Privacy & Security → Open Anyway** (on macOS 14 or older: right-click Scorpion in Applications → **Open**).

## What's new since 0.1.32

- **New model: Qwopus3.5 9B v3 (abliterated)**, 6.9 GB (Q6_K), in the model list. It is too big for the installers and the USB system, so it is a download from **Models**.
- **Nemotron 3.5 Lightning is no longer offered.** A copy you already downloaded keeps working.

Scorpion OS (the Linux system you can boot from a USB stick) and the Linux packages come from the **Scorpion OS** workflow, not this release.
